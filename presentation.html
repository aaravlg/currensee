02 · Training the Model

03 · Under the Hood

Transfer Learning, Not From Scratch

Instead of teaching a model to understand images from zero (which needs millions of photos), we start from MobileNet — a model already trained on millions of general images — and fine-tune just its final layers on our currency photos.

Why this works

  • Early layers already know edges, colors, textures
  • We only retrain the "what does this pattern mean" layer
  • Needs far fewer images, trains in minutes not days

Tools used

Teachable Machine MobileNet TensorFlow.js
04 · Live Prediction Pipeline

From Camera Frame to Spoken Word

Everything below happens entirely inside the browser — no server, no internet required once the page has loaded.

1. Webcam frame captured (320×320)
2. Fed into MobileNet-based classifier
3. Confidence score computed per class
4. If below 75% confidence → "try again"
5. Otherwise → Speech Synthesis API speaks result
05 · Deployment

Runs Anywhere, No Install Needed

Because it's a webapp — not a native app — anyone can use it by opening a link in their phone's browser.

  • Hosting: Static files served via GitHub Pages / Firebase — no backend server
  • Offline capable: Once loaded, inference and speech both run fully on-device
  • Cross-platform: Same code works on Android, iOS, and desktop browsers

This design choice matters: most people needing this tool already own a smartphone with a screen reader — no separate hardware required to benefit.
